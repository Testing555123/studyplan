## 用户需求

对 `docs/TECH-SELECTION.md` 的「最终选型」做全量复核：覆盖 §1 已选型表格及 §2–§12 所有被排除/对照的候选库（含框架、后端/低代码、认证、ORM、业务层、平台级、本地模型等）。

## 核心内容

- 用实时数据源核验每个项目的 stars、license(spdx)、pushed_at 与最新版本号：GitHub REST API 取仓库活跃度，npm registry 取发版版本，HuggingFace 取模型可用性。
- 将核验结果与仓库实际 `package.json` 已装版本对账，标出不代表最新或文档过期的数字。
- 重点复核文档自标的时效风险项：Payload v4 是否仍处 canary、Next.js 16.4 生产就绪度、better-auth/Drizzle/Fumadocs 当前版本、Qwen3 ONNX 权重是否仍可获取且 Apache-2.0。
- 交付形式为直接更新 `TECH-SELECTION.md`：新增「再调研·复核」区块，就地修正全部过期数字、版本与判定，保留可追溯说明。
