# StudyPlan 品牌规范（Brand Guidelines）

> 本文档是「设计」章节中设计审计与 V3 品牌升级的产物，定义 logo、色彩语义、信息层级与品牌语气。
> 它是**决策记录 + 使用约束**，不是设计稿；图形资产在 `apps/web/public/`。

---

## 1. Logo

### 1.1 形态

| 文件 | 用途 | 说明 |
|---|---|---|
| `public/favicon.svg` | 浏览器标签 / 书签 | 仅图标（青蓝圆角方块 + 白色火花），矢量，全尺寸自适应 |
| `public/favicon.ico` | 旧浏览器兜底 | 含 16/32/48/64/128/256px 多尺寸 |
| `public/icon-180.png` | iOS 主屏 | `apple-touch-icon`，PNG（iOS 不接受 svg） |

> 精简后只保留上述资产。原先的 `icon-{16,32,48,64,128,192,512}.png` 与 `logo.svg`
> 在 `nuxt.config.ts` 与任何组件里都**没有被引用**（本项目也没有 PWA manifest），
> 保留只会让人误以为「换 logo 要改十个档」，因此一并删除。

### 1.2 最小尺寸与留白

- 图标最小可识别尺寸：**16px**（favicon 下限）。
- 字标最小尺寸：**120px 宽**（低于此宽度字距会被挤压，改用纯图标）。
- 安全留白：图标四周保留 ≥ 圆角方块边长的 25% 空白，不可贴边裁切。

### 1.3 单色与反白

- **彩色版**：方块 `#06b6d4`（brand-500），火花 `#ffffff`。用于浅色背景。
- **单色版（深底）**：整图标转 `#ffffff` 或当前文字色，保持形状，不保留青蓝。
- **禁用**：
  - 不可改方块圆角比例（rx 固定为边长的 22%）；
  - 不可把火花换成其他图标；
  - 不可给方块加渐变或投影（保持扁平）；
  - 不可在青蓝方块上叠深蓝火花（对比丢失）。

## 2. 色彩语义

主色与 AI 色是**两套冷暖对立的语义色**，这是本品牌的核心识别：

| 语义 | 亮色 | 暗色 | 用途与对比度 |
|---|---|---|---|
| 主色 `brand` | `brand-700 #0e7490`（实心底） | `brand-400 #22d3ee` | 主按钮、链接、焦点环。白字 on brand-700 = **5.36:1** ✅ |
| AI 色 `ai` | `ai-600 #7c3aed`（实心底） | `ai-400 #a78bfa` | AI 助手图标与按钮。紫罗兰，与主色冷暖对立，**一眼可辨**。白字 on ai-600 = **5.70:1** ✅ |

> ⚠️ **为什么 AI 用紫罗兰而不是青蓝**：主色是青蓝（冷），AI 用紫罗兰（暖偏紫）形成冷暖对比，让「AI 功能」与主功能在视觉上天然分离。这是 `main.css` 中 `--color-ai-*` 一贯声明的设计意图，V3 已落实。

次级文字色走 Nuxt UI 语义层：`text-muted`（4.80:1）、`text-toned`（7.63:1）、`text-dimmed` **仅用于纯装饰**（2.52:1，不可用于需阅读的正文）。

## 3. 信息层级（四级）

V3 统一为四级，任何页面都按此组织：

| 层级 | 语义 | 令牌 / 类 | 字阶 | 字重 |
|---|---|---|---|---|
| L1 | 页面主标题 | `text-display` / `text-3xl` | 30px | 700 |
| L2 | 区块标题 | `text-heading` / `text-2xl` | 24px | 600 |
| L3 | 卡片 / 链接标题 | `text-title` / `text-xl` | 20px | 600 |
| L4 | 正文 | `text-body` / `text-base` | 16px | 400 |

辅助层：`text-caption`（12px）、`text-eyebrow`（12px + `tracking-eyebrow` 0.18em 大写）用于分组小标题（如页脚「学习 / 社区 / 项目」）。

## 4. 品牌语气与术语

### 4.1 语气

- **技术、直接、不浮夸**：用「做了什么、怎么用」，不用「颠覆、赋能、一站式」等空泛词。
- **与第一人称一致**：站点自称 `studyplan` 或「我们」，不混用「本站 / 本平台 / 该应用」。
- **鼓励动手**：文案多给可执行下一步（「跟着路线走」「打开项目试试」），少描述状态。

### 4.2 术语表（统一写法）

| 推荐 | 不推荐 | 说明 |
|---|---|---|
| 学习路线 | 学习路径 / roadmap | 全站统一「路线」 |
| 帖子 | 文章 / 博客 | 社区内容统称「帖子」 |
| 全栈 | full-stack / 全端 | 中文语境用「全栈」 |
| GitHub 热门 | trending / 排行榜 | 对应 `/trending` 页 |
| 配套电子书 | 教程 / 指南 PDF | 明确是「书」 |

### 4.3 大小写

- 代码 / 技术专有名词保留原大小写：`Nuxt`、`NestJS`、`MongoDB`、`TypeScript`、`CI/CD`。
- 中文文案中的英文产品名不强行翻译。

## 6. 动效与装饰原则

### 6.1 装饰哲学

**界面静止时绝对安静。** 装饰层只承担「品牌记忆点」，不承载信息，不与内容争夺注意力。任何新增装饰动效前先过四问：承载信息？无限运行？`prefers-reduced-motion` 生效？会进内页吗？

### 6.2 动效令牌

| 动效 | 触发 | 参数 | 用途 |
|---|---|---|---|
| `ring-breathe` | 常驻（无限） | `8s ease-in-out infinite`；`opacity .35↔.55`；`scale 1↔1.02` | 仅头像光环装饰，**无信息语义** |
| `gradient-pan` | 仅 `:hover` / `:focus-within` | `9s linear`，静止停在 `background-position: 50%` | `.gradient-frame` 边框流动，纯装饰 |

> **推測**：`gradient-pan` 在触摸端无 hover，故永不显示；因其纯装饰、无信息，此取舍可接受。

### 6.3 减弱动效（prefers-reduced-motion）

双层处理（`main.css` **L449–459** 全局压时长 + **L937–966** 装饰层 `animation:none`）。对前庭功能障碍用户，所有无限动效**完全停止**。对应 `ui-ux-pro-max` Pre-Delivery Checklist 的 reduced-motion 必查项 ✅。

### 6.4 品牌资产字体依赖

> 本条原本记录 `logo.svg` 字标内嵌 `Inter` 的字体依赖。该档案已随未使用资产一并删除
> （`nuxt.config.ts` 与组件均未引用），故此顾虑不再适用。
> 现行品牌呈现改用页头与页脚的品牌方块（`bg-primary` + `i-lucide-sparkles`），
> 不依赖任何自托管字体档。
