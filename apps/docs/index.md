## 这个项目在做什么

一个**学习/技术分享社区**：注册账号、用 Markdown 写技术文章、打标签，
其他人可以浏览、点赞、评论、按标签筛选。发帖时系统自动生成摘要与推荐标签。

功能刻意做得很小（6 项，MVP），因为**目标不是功能多，而是链路完整**：
浏览器 → 前端框架 → HTTP → 后端框架 → 数据库 → 再返回渲染成页面。

## 你会学到什么

| 层次 | 内容 |
| --- | --- |
| 语言 | TypeScript 的类型系统、泛型、装饰器、模块化 |
| 前端 | Nuxt 4 的文件路由、自动导入、SSR、组合式函数、Pinia 状态管理 |
| 后端 | NestJS 的模块 / 依赖注入 / 守卫 / 管道 / 拦截器 / 异常过滤器 |
| 数据库 | MongoDB 文档建模、Mongoose Schema、索引、原子更新、聚合 |
| 网络 | REST 设计、HTTP 状态码、CORS 与凭据、JWT 双 Token 认证 |
| AI | Prompt 模板、结构化输出、超时与降级、把 LLM 安全地接进业务链路（当前该功能已停用，依赖已移除） |
| 工程 | monorepo、Git 工作流、代码规范、单测、E2E、部署 |

## 学习方式

> **先讲原理 → 再写最小可运行实现 → 你验证能跑 → 才进入下一阶段。**

不追求"一次给完整成品"。因为看懂一份成品代码，和亲手把它长出来，
是两种完全不同的能力。

## 一条纪律

真实密钥只写在 `apps/api/.env` 里，这个文件**永远不会**进入 Git。
仓库里只保留空值的 `.env.example`。
